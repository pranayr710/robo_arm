Build order

  1. Bench-test each servo alone (signal→PA0, red→5V rail, brown→GND). Send S 0 90 — horn should sweep cleanly.
  2. Centre every servo to 90° before screwing on the horns, then assemble the arm frame.
  3. Build the power rails from the 5V 5A SMPS; add 2×1000 µF caps. Servo reds → 5V rail, browns → GND rail.
  4. Wire the Blue Pill: servo signals to PA0–PA3, power to its 5V/GND pins (never power servos from the board).
  5. Flash firmware/ via ST-Link (SWD). On boot it prints READY v3.0; P→PONG.
  6. Calibrate live with C ch minUs maxUs, then add joystick (VCC = 3.3 V!), HC-SR04, and HC-05.
  7. Run python host/server.py --port COMx, open the app, and type write HI.
